# ホテル一楽周辺 子連れ祝日ディナー探索ガイド プロジェクト開発ルール

> [!IMPORTANT]
> 本リポジトリは、福岡市中央区「ホテル一楽」周辺の飲食店（全60+店舗）を子連れ祝日ディナー目線で検索・絞り込みできるWebアプリ（GitHub Pages公開）です。
> リポジトリ: `https://github.com/nonoHP/Food.git` (ブランチ: `main`)

## 1. 文字コードの絶対ルール（UTF-8 厳守 & BOM保護）
- **PowerShellの直接編集禁止**: PowerShellの `Set-Content`, `Get-Content`, `>`, `>>` は UTF-16LE 変換され、文字化けを引き起こすため絶対に使用しないこと。
- **CSVのBOM保護**: `restaurants.csv` は Excel 等との互換性のため UTF-8 (BOM付き) で管理されています。Python で編集する際は `encoding='utf-8-sig'` を指定すること。
- **HTML編集**: `index.html` は UTF-8 (BOMなし) で編集すること。

## 2. データ構造と整合性の絶対厳守
- **`restaurants.csv` の15カラム仕様**:
  1. `ID` (数値)
  2. `店名` (店舗名称)
  3. `読みがな` (ひらがな)
  4. `エリア` (渡辺通、清川、高砂、薬院など)
  5. `徒歩` (徒歩○分)
  6. `祝日営業状況(open/closed/caution)` (open, closed, caution)
  7. `祝日営業時間` (例: 17:00〜23:00)
  8. `親子予算` (例: 2,000円〜3,500円)
  9. `席タイプ` (小上がり座敷、テーブル、個室など)
  10. `禁煙環境` (全席禁煙、分煙など)
  11. `特徴・ハイライト`
  12. `子連れポイント` (お子さま食器、やわらかいメニューなど)
  13. `グルメサイト名(食べログ/ホットペッパー/ぐるなび)`
  14. `グルメURL`
  15. `Googleマップ検索名`
- カラムの順序やヘッダー名を変更しないこと。

## 3. UI/UX 機能の保全
- **`index.html` 内の機能保全**:
  - インクリメンタルリアルタイム検索
  - カテゴリ絞り込みボタン（徒歩3分、座敷・小上がり、うどん、もつ鍋など）
  - スマートソート（おすすめ順、距離順、予算順、開店時刻順）
  - LocalStorage を利用したお気に入り保存機能
  - Googleマップ連携リンク
- これらの中核スクリプト・スタイルを誤って削除・破損させないこと。

## 4. 完全自動コマンド実行＆GitHub自動デプロイ絶対ルール
- **ユーザーへコマンド実行を絶対に求めない**: ビルド、Gitコミット、Gitプッシュ等のいかなるコマンド操作も、ユーザーに手動実行を依頼してはならない。すべてAI自身が自律的に全自動実行・完遂すること。
- **修正完了後の自動 GitHub デプロイ（Git Push）義務**: 作業完了後は自律的に `git add .` → `git commit` → `git push origin main` を一括で実行し、GitHub Pages への公開を完了させること。
- **エラー時の自律代替実行**: コマンドエラーが発生してもユーザーに尋ねず、代替スクリプト（Python `subprocess` 等）を作成して自律完遂すること。
