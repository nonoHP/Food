# ホテル一楽周辺 子連れ祝日ディナー探索ガイド

福岡市中央区清川の「ホテル一楽」周辺（渡辺通・薬院・高砂・清川）における、5歳児連れでの安心ディナー向けWeb探索ナビゲーションです。全60店舗の祝日営業情報、座敷・小上がり有無、ホテルからの徒歩所要時間、受動喫煙対策状況などを網羅しています。

## 🌟 主な機能
- **リアルタイム検索**: 店名・ジャンル・キーワードによるインクリメンタル検索
- **カテゴリー絞り込み**:
  - ホテル徒歩3分以内
  - 座敷・小上がり・個室あり
  - 定番定食・うどん
  - ご当地グルメ（もつ鍋・水炊き・焼鳥）
  - 安くて美味しい・中華・居酒屋
  - 食べ放題・焼肉
  - 上質・ホテル内
  - 祝日休業などの注意店
- **スマート並び替え**: おすすめ順、ホテルからの距離順、予算順、開店時刻順
- **お気に入り保存**: 気になる店舗をローカルストレージで保存・一覧表示
- **Googleマップ連携**: 各店舗のルート案内・口コミへ1タップで遷移

## 🛠 技術構成
- HTML5 / Vanilla JavaScript
- Tailwind CSS (CDN)
- Font Awesome 6
- Google Fonts (Noto Sans JP, Inter)

## 🚀 GitHub Pages での公開方法
1. GitHub で新しいリポジトリを作成（Public推奨）
2. 本リポジトリのコードをプッシュ
3. リポジトリの **Settings** > **Pages** で、Branch を `main`、Folder を `/ (root)` に設定して保存
4. 数分後に公開URLが発行されます
